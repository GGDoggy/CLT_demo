# 互動式中央極限定理（CLT）Demo 網頁製作計畫

## Summary

建立一個教學用的互動式 HTML 網頁，讓使用者先以手繪方式建立定義於 `[-1, 1]` 的連續單一自旋機率分布，再觀察 `n` 個獨立自旋相加後的分布如何與具有相同期望值與變異數的常態分布比較。

網頁同時提供 **Ising model with external field** 模式。切換後停用手繪輸入，改由 Field Strength、Temperature 與 discrete spin 設定產生離散自旋分布。

另一個互動區域建立 `rows × cols` 的獨立自旋格點，按照目前的單一自旋分布反覆取樣，記錄所有自旋的平均值，並以時間序列圖呈現平均值相對於理論期望值與標準誤差範圍的變化。

使用者主要透過改變原始分布、`n`、外場參數及格點模擬參數來觀察 CLT demo 中的分布變化；網頁重點是**即時互動、計算結果與圖表同步**，而非課本文字說明。

## 使用者流程

1. 開啟網頁後，預設進入手繪模式。
2. 使用者看到 `[-1, 1]` 的手繪區域，並可在其中畫出一筆非負的連續分布曲線。
3. 使用者完成一筆後，手繪框自動鎖定。
4. 網頁依照 `sample points` 將手繪曲線取樣，視為機率密度函數，進行數值積分與正規化。
5. 正規化後的單一自旋分布重新畫在原手繪框中，同時顯示單一自旋的期望值 `μ` 與標準差 `σ`。
6. 網頁依目前的 `n` 計算單一自旋分布的 `n` 次卷積，得到 `n` 個自旋**相加後**的分布。
7. 同一張圖中顯示相加分布與具有相同期望值及標準差的常態分布。
8. 使用者拖動 `n` 滑桿時，網頁即時重新計算相加分布與對應常態分布，並同步更新相關統計值。
9. 使用者可以開啟 `center normal on x-axis`，讓相加分布圖以相加後理論期望值 `nμ` 為中心調整 x 軸顯示範圍。
10. 網頁同時建立 `rows × cols` 個彼此獨立的自旋格點。此處目前設定為預設 `10 × 10`。
11. 使用者按下 **Play** 後，每隔 `interval` 毫秒重新獨立取樣所有格點。
12. 每次取樣完成後，計算所有格點的平均值，將結果加入歷史資料並更新平均值時間序列圖。
13. 平均值圖同時顯示理論期望值與標準誤差範圍。
14. 使用者可以開啟 `center mu on y-axis`，使 y 軸以理論期望值 `μ` 為中心自動調整顯示範圍。
15. 按下 **Pause** 後停止持續取樣，但保留既有歷史資料。
16. 按下 **Reset** 後只清除平均值歷史；目前分布及其他控制參數保持不變。
17. 使用者按下「重繪」後重新開放手繪輸入，但保留原本曲線與模擬歷史。新曲線完成後取代原本的手繪分布。
18. 使用者可以切換至 **Ising model with external field**。
19. 外場模式下停用手繪輸入，改由 Field Strength、Temperature 與 discrete spin 選項決定原始自旋分布。
20. 修改外場參數時，立即重新計算單一自旋分布、統計量、`n` 次相加結果與格點取樣所使用的分布。
21. 從外場模式返回手繪模式時，恢復切換前保留的手繪分布。

## 原始分布建立方式

### 手繪模式

手繪區域的 x 軸固定為：

- `-1 ≤ x ≤ 1`

使用者以滑鼠或觸控畫出**一筆**非負分布曲線。

手繪完成後：

1. 取得手繪曲線。
2. 在 `[-1, 1]` 上依 `sample points` 進行取樣。
3. 將取樣結果解讀為機率密度函數的數值。
4. 若取樣結果存在負值，應視為無效輸入，而不是默默產生負機率。
5. 透過數值積分計算密度總量。
6. 將密度除以積分值，使總機率密度為 `1`。
7. 以正規化後的密度作為後續單一自旋分布。

`sample points` 控制數值表示使用的離散取樣點數，設定為：

- 預設值：`200`
- 最小值：`1`
- 最大值：`100`

x 軸代表單一自旋值 `x`。

y 軸代表正規化後的**機率密度** `p(x)`。

單一自旋期望值依機率密度計算：

`μ = ∫ x p(x) dx`

標準差由變異數計算：

`σ = sqrt(∫(x-μ)²p(x)dx)`

手繪完成並正規化後，在原手繪框中改為顯示計算得到的機率密度曲線，而不是只保留原始手繪筆跡。

### 外場模式

啟用 **Ising model with external field** 後：

- 停用手繪輸入。
- 使用標準無因次化的獨立離散自旋 Boltzmann 分布。
- discrete spin 選項控制離散自旋設定。
- Field Strength 與 Temperature 改變時即時重新產生單一自旋分布。

Field Strength：

- 預設值：`0`
- 最小值：`-10`
- 最大值：`10`

Temperature：

- 預設值：`1`
- 最小值：`0.01`
- 最大值：`100`

外場模式下的具體離散 spin 選項依前述設定採用離散自旋模型；實作時應將選定 spin state 與其 Boltzmann weight 正規化為機率後，再計算 `μ`、`σ` 及後續分布。

關閉外場模式後，不應用外場模式的分布覆蓋手繪分布，而應恢復先前保存的手繪分布。

## CLT 展示方式

CLT 的主要展示對象是：

> `n` 個獨立自旋相加後的分布。

因此主要圖表呈現：

- 原始單一自旋分布經 `n` 次卷積後的分布。
- 與其匹配的一個常態分布。

若單一自旋為 `X`，其統計量為 `μ` 與 `σ`，則相加後變數：

`S_n = X₁ + X₂ + ... + X_n`

其理論平均值與標準差為：

- 平均值：`nμ`
- 標準差：`σ√n`

對應的常態分布使用相同的平均值與標準差。

`n` 控制：

- 預設值：`1`
- 最小值：`1`
- 最大值：由 `max n` 決定

`max n`：

- 預設值：`1`
- 最小值：`1`
- 最大值：`100`

因此 `max n` 必須同時控制 n 滑桿的最大可選值。

當 `n` 改變時，需要同步重新計算：

- `n` 次相加分布
- 對應常態分布
- 相加後理論期望值
- 相加後理論標準差
- 圖表顯示範圍（若啟用 `center normal on x-axis`）

不將這個區域改成平均值分布；主要 CLT 圖固定展示使用者指定的**相加後分布**。

## 圖表與統計

### 圖表一：單一自旋機率分布

**標題：**

`Single Spin Probability Distribution`

**x 軸：**

單一自旋值，固定範圍 `[-1, 1]`。

**y 軸：**

機率密度。

**視覺形式：**

使用連續曲線呈現正規化後的機率密度。

**圖例：**

至少標示目前的單一自旋機率分布。

**統計值：**

- `μ`
- `σ`

數值固定顯示至小數點後 3 位。

圖表必須與目前模式同步：

- 手繪模式 → 顯示手繪所得分布。
- 外場模式 → 顯示外場模型所得分布。

### 圖表二：n 個自旋相加分布

**標題：**

`Distribution of the Sum of n Independent Spins`

**x 軸：**

`n` 個自旋相加後的值 `S_n`。

**y 軸：**

相加結果的機率密度。

**視覺形式：**

同一座標系中使用兩條曲線：

- n 次卷積得到的實際相加分布
- 對應常態分布

**圖例：**

- `n-fold Convolution`
- `Normal Distribution`

同時顯示：

- `n`
- 單一自旋 `μ`
- 單一自旋 `σ`
- 相加後平均值 `nμ`
- 相加後標準差 `σ√n`

數值固定顯示至小數點後 3 位。

`center normal on x-axis` 開啟後，x 軸以 `nμ` 為中心自動調整顯示範圍；關閉時使用適合目前相加分布的正常顯示範圍。

### 圖表三：自旋格點平均值

**標題：**

`Mean Spin vs Time`

**x 軸：**

取樣次序／step。

**y 軸：**

每次取樣時所有格點的平均自旋值。

**視覺形式：**

時間序列折線圖。

**圖例：**

- `Sample Mean`
- `Theoretical Mean`
- `Standard Error`

理論期望值以水平參考線表示。

標準誤差範圍使用：

`μ ± σ/√N`

其中：

`N = rows × cols`

標準誤差範圍應以陰影區域或上下界線清楚呈現。

`center mu on y-axis` 開啟後，以理論期望值 `μ` 為中心自動調整 y 軸顯示範圍。

## 互動控制

| 控制項 | 預設值 | 範圍／狀態 | 用途 |
|---|---:|---|---|
| 手繪框 | 開啟 | `[-1,1]` | 建立連續單一自旋分布 |
| Sample Points | `200` | `1–100` | 控制手繪分布的數值取樣點數 |
| 重繪 | — | 按鈕 | 重新開放手繪輸入並保留既有曲線與模擬歷史 |
| Ising model with external field | 關閉 | On/Off | 在手繪分布與外場模型間切換 |
| Field Strength | `0` | `-10–10` | 控制外場模型 |
| Temperature | `1` | `0.01–100` | 控制外場模型 |
| discrete spin | — | 選項 | 選擇外場模式使用的離散自旋 |
| n | `1` | `1–max n` | 控制 n 次相加 |
| max n | `1` | `1–100` | 控制 n 滑桿最大值 |
| center normal on x-axis | 關閉 | On/Off | 以相加後期望值為中心調整 x 軸 |
| interval | `50 ms` | `10–1000 ms` | 控制格點重新取樣頻率 |
| rows | `10` | `1–100` | 格點列數 |
| cols | `10` | `1–100` | 格點欄數 |
| Play | — | 按鈕 | 開始持續取樣 |
| Pause | — | 按鈕 | 暫停取樣並保留歷史 |
| Reset | — | 按鈕 | 清除平均值歷史並重新開始模擬 |
| center mu on y-axis | 關閉 | On/Off | 以理論期望值為中心調整 y 軸 |

`max n` 改變時，n 滑桿的最大值必須同步更新；如果目前 `n` 超過新的 `max n`，應將 n 調整到合法範圍。

修改 Field Strength、Temperature 或 discrete spin 後：

- 立即重新計算單一自旋分布。
- 立即更新 `μ`、`σ`。
- 立即更新 `n` 次相加分布。
- 立即更新常態分布。
- 後續格點取樣使用新的單一自旋分布。
- 既有平均值歷史不因單純修改外場參數而自動清除。

## Error Handling

### 無效數字

對所有數值輸入檢查：

- 空值
- 非數字
- 無限值
- 不符合指定範圍的數值

輸入無效時應：

1. 顯示清楚的欄位錯誤提示。
2. 不使用無效值進行計算。
3. 保留上一個有效設定，直到使用者輸入有效值。

### 不合理的參數

檢查：

- `n < 1`
- `max n < 1`
- `n > max n`
- `rows < 1`
- `cols < 1`
- `interval < 10 ms`
- `interval > 1000 ms`
- `sample points < 1`
- Field Strength 超出 `[-10,10]`
- Temperature 不在 `[0.01,100]`

### 無效手繪分布

若手繪結果：

- 沒有任何有效點
- 整條曲線為零
- 含有負值
- 數值積分結果為零或非有限值

則不能正規化。

應顯示例如「無法形成有效機率分布，請重新繪製」的錯誤狀態，並保持手繪區域可重新輸入。

### 正規化失敗

任何情況下若機率密度／離散權重的總量無法得到有限且大於零的數值：

- 停止後續計算。
- 不更新目前有效分布。
- 顯示錯誤提示。

### n 或卷積計算過大

若 `n` 或 `max n` 導致離散卷積的資料量過大：

- 不讓瀏覽器主執行緒長時間無回應。
- 顯示計算中的狀態。
- 必要時警告使用者目前設定可能需要較長計算時間。
- 保留上一個有效圖表，直到新計算完成。

### 沒有圖表資料

在沒有有效原始分布之前：

- n 次相加圖不應顯示虛假的資料。
- 平均值圖也不應開始模擬。

應顯示明確的「請先建立有效的單一自旋分布」狀態。

### 模式切換

切換外場模式時，如果外場分布計算失敗，不應覆蓋原本有效的手繪分布。

返回手繪模式時必須恢復先前保存的手繪分布。

## Performance

主要效能風險包括：

- `sample points` 改變後的數值計算。
- n 次卷積。
- 大量 rows × cols 自旋的持續取樣。
- 高頻率 `interval` 下的圖表更新。
- 大量歷史資料造成圖表繪製負擔。

### 分布計算

應將「原始分布建立」與「n 次相加」分開處理。

原始分布未改變時，不應因為使用者只拖動 n 而重新取樣手繪曲線。

應快取至少：

- 正規化後的單一自旋分布。
- 單一自旋 `μ`。
- 單一自旋 `σ`。
- 可重用的卷積中間結果。

當 n 改變時，只需要重新取得對應的 n 次卷積結果。

### 外場模式

Field Strength、Temperature 或 discrete spin 改變時，原有手繪分布相關快取保持不變；外場分布相關快取則失效並重新計算。

### 模擬更新

Play 使用定時器按照 `interval` 執行一次完整的格點取樣。

每次取樣：

1. 產生 `rows × cols` 個獨立自旋。
2. 計算一次平均值。
3. 將單一平均值加入歷史。
4. 更新圖表。

不應在每個格點完成取樣時分別重繪圖表。

### 歷史資料

平均值歷史可能長時間累積，因此應避免每次更新都重新建立整份大型圖表資料結構。

圖表只需保存目前必要的時間序列資料。

若瀏覽器繪圖效能開始受到歷史資料數量影響，可以降低**顯示點數**，但不得改變已計算的統計結果。

### UI responsiveness

需要避免在滑桿快速拖動時對每一個中間值進行昂貴的完整計算。

可以採取：

- 快取。
- 計算排程。
- 延遲／合併快速連續的更新請求。
- 將昂貴計算分段執行。

如果實作環境允許且確有必要，可將大型卷積計算移至背景執行環境，避免阻塞 UI。

## 介面與版面

整體應設計成**教學用互動工具**，而不是行銷頁。

### 主要區塊

建議分成以下功能區：

1. **原始分布區**
   - 手繪框。
   - Sample Points。
   - 重繪控制。
   - 單一自旋 `μ`、`σ`。
   - 外場模式切換。
   - 外場相關控制項。

2. **CLT 分布區**
   - n 與 max n。
   - center normal on x-axis。
   - n 次相加分布圖。
   - 常態分布。
   - 相加後統計值。

3. **自旋格點模擬區**
   - rows。
   - cols。
   - interval。
   - Play / Pause / Reset。
   - 格點本身的即時狀態視覺化。

4. **平均值時間序列區**
   - 平均值圖。
   - 理論期望值。
   - 標準誤差範圍。
   - center mu on y-axis。

### 狀態辨識

介面應清楚顯示目前處於：

- 手繪模式／外場模式。
- 手繪框目前是「可輸入」或「已鎖定」。
- 是否正在 Play。
- 是否正在計算。
- 目前使用的 `n`。
- 目前有效的單一自旋分布。

### 手繪互動

手繪區域應具有明確的邊界與 `[-1,1]` x 軸刻度。

在手機上：

- 手繪區支援觸控。
- 控制項與圖表採響應式排列。
- 不應要求使用者精確操作過小的控制元件。

桌面版可將控制區與圖表區並列；較窄螢幕則改為垂直排列。

## 測試項目

### 初始載入

- 網頁可以正常載入。
- 預設進入手繪模式。
- 手繪框可以接受一筆輸入。
- 所有控制項顯示正確預設值。
- 未建立有效分布前，不顯示虛假的 CLT 或模擬結果。

### 建立原始分布

- 畫出有效非負曲線。
- 完成後手繪框鎖定。
- 正確按照 sample points 取樣。
- 機率密度正確正規化。
- `μ`、`σ` 正確計算。
- 正規化後曲線正確回畫至手繪框。

### CLT

- `n=1` 時相加分布與原始分布一致。
- 改變 n 時卷積結果正確更新。
- 常態分布的平均值為 `nμ`。
- 常態分布的標準差為 `σ√n`。
- n 快速改變時 UI 不會長時間失去回應。
- center normal on x-axis 開關正確影響 x 軸。

### 格點模擬

- `rows=1, cols=1` 時平均值等於單一取樣值。
- `10 × 10` 格點可以正常建立。
- Play 開始產生新取樣。
- Pause 停止取樣。
- Reset 清除平均值歷史。
- interval 改變後取樣頻率同步改變。
- 格點每次取樣彼此獨立。
- 平均值圖與實際取樣結果同步。

### 統計

- 理論期望值與目前分布一致。
- 標準誤差使用 `σ/√(rows×cols)`。
- 理論平均值線與目前分布同步。
- center mu on y-axis 正確以 `μ` 為中心調整 y 軸。

### 重繪

- 原曲線可以重新開放編輯。
- 重繪期間原本模擬歷史仍存在。
- 新曲線完成後正確取代舊分布。
- 新分布會更新 CLT 結果。
- 新分布會成為後續格點取樣來源。
- Reset 的語義不被重繪操作破壞。

### 外場模式

- 啟用後手繪輸入停用。
- Field Strength 在 `[-10,10]` 內有效。
- Temperature 在 `[0.01,100]` 內有效。
- 修改外場參數後分布與統計值立即更新。
- n 次相加結果同步更新。
- 格點後續取樣使用新的分布。
- 關閉外場模式後恢復原本手繪分布。

### 錯誤輸入

測試：

- 空欄位。
- 文字。
- 小數。
- 負值。
- 超出範圍。
- `Temperature = 0`。
- `n > max n`。
- 空白手繪框。
- 全零曲線。
- 無效或無法正規化的曲線。

每種情況都應產生明確且不會破壞上一個有效狀態的錯誤處理。

### 大量計算

測試：

- `sample points = 100`
- `n = 100`
- `rows = 100`
- `cols = 100`
- `interval = 10 ms`

確認：

- UI 不會明顯卡死。
- 圖表仍可操作。
- Play / Pause 可以正常控制。
- 計算中的狀態清楚可見。

### 響應式版面

至少測試：

- 桌面寬螢幕。
- 一般筆電寬度。
- 平板。
- 手機直向。
- 手機橫向。

確認手繪、控制項、格點模擬器、兩張主要圖表及統計值均不會互相遮蔽或溢出畫面。

### 最終同步性測試

確認以下狀態永遠使用同一個「目前有效單一自旋分布」：

- 單一自旋圖。
- `μ`、`σ`。
- n 次相加分布。
- 常態分布。
- 自旋格點取樣。
- 理論平均值。
- 標準誤差。

特別測試「重繪 → 改 n → Play → Pause → 切換外場 → 修改 Temperature → 回到手繪 → Reset」的連續操作，確保所有狀態與圖表仍保持一致。
