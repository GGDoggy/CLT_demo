# 互動式中央極限定理：手繪 PDF 與 n 重和分布 Demo

## Summary

建立一個完全離線、單一 HTML 檔案的互動式教學工具。使用者可以在座標框中以一筆劃建立連續型機率密度函數（PDF），網頁會將筆畫轉換、正規化並計算原始分布的期望值與標準差。

使用者可透過整數滑桿調整獨立同分布隨機變數的相加次數 (n)。網頁需即時計算並繪製

[
S_n=X_1+X_2+\cdots+X_n
]

的 PDF，同時比較數值卷積結果的統計值與理論值 (n\mu)、(\sqrt{n}\sigma)。

本 Demo 只呈現相加後的分布，不繪製平均分布，也不疊加常態分布曲線。使用者主要透過改變 (n)，觀察相加分布的形狀、位置與尺度如何變化。

## 使用者流程

1. 使用者開啟 HTML 後會看到：

   * 頁面標題與簡短操作說明。
   * (x_{\min}) 與 (x_{\max}) 輸入框，預設為 0 與 10。
   * 一個處於可繪製狀態的原始分布座標框。
   * 「重繪」按鈕；初始繪圖期間應停用，或以狀態文字清楚表示目前已可直接繪製。
   * (n_{\max}) 輸入框，預設為 30。
   * (n) 滑桿，預設為 2，範圍為 2 至目前的 (n_{\max})。
   * 尚無結果的相加分布圖與統計區，顯示「請先畫出有效的原始分布」。

2. 使用者在原始分布座標框中按下滑鼠或觸控筆，從左向右畫出一筆曲線。

3. 繪圖期間：

   * 顯示即時筆畫。
   * 允許少量水平抖動。
   * 如果筆畫明顯向左回頭，立即標示該筆畫無效，並提示必須大致由左向右繪製。
   * 一次只接受一筆劃；放開指標即代表輸入完成。

4. 有效筆畫完成後：

   * 鎖定手繪框。
   * 將曲線轉換成非負權重，數值積分後正規化為 PDF。
   * 用正規化後的 PDF 取代輸入筆畫，繪製在同一張圖、相同的 x 位置。
   * 自動調整 y 軸，使其顯示實際機率密度。
   * 計算並顯示原始分布的期望值與標準差。
   * 計算預設 (n=2) 的相加分布，更新第二張圖及其統計值。

5. 使用者拖曳 (n) 滑桿時：

   * 滑桿旁同步顯示目前整數 (n)。
   * 重新取得或計算 (n) 重卷積結果。
   * 更新相加分布圖的標題、座標範圍、曲線與統計值。
   * 原始分布圖不變。

6. 使用者修改 (n_{\max}) 時：

   * 驗證新值是否為 2 至 100 的整數。
   * 更新 (n) 滑桿上限。
   * 若目前 (n) 大於新的 (n_{\max})，將 (n) 自動調整為新的 (n_{\max})，並立即更新結果。
   * 重新建立與 (n_{\max}) 有關的卷積計算配置及快取。

7. 使用者修改 (x_{\min}) 或 (x_{\max}) 時：

   * 已接受的筆畫不需重畫。
   * 將筆畫原本的水平相對位置映射到新的 x 軸範圍。
   * 重新正規化 PDF。
   * 重新計算原始分布及所有目前需要的相加分布結果。
   * 同步更新兩張圖的座標與統計值。

8. 使用者按下「重繪」後：

   * 保留目前已接受的 PDF，不立即清除。
   * 解鎖手繪框。
   * 按鈕文字改成「取消重繪」。
   * 狀態提示改為「請由左向右畫出新的分布」。
   * 舊曲線在新筆畫開始及繪製期間仍以淡色參考線保留。

9. 如果使用者完成新的有效筆畫：

   * 新筆畫取代舊分布。
   * 手繪框再次鎖定。
   * 按鈕恢復為「重繪」。
   * 清除依賴舊分布的卷積快取。
   * 重新計算兩張圖與全部統計值。

10. 如果使用者按下「取消重繪」：

    * 放棄尚未完成或尚未接受的新筆畫。
    * 保留並恢復原本的 PDF。
    * 鎖定手繪框。
    * 按鈕恢復為「重繪」。
    * 不重新計算未發生變化的資料。

## 原始分布建立方式

### 使用者輸入

使用者提供：

* 一筆由左向右繪製的曲線。
* (x_{\min})，預設 0。
* (x_{\max})，預設 10。

(x_{\min}) 與 (x_{\max}) 可為任意有限實數，但必須滿足：

[
x_{\min}<x_{\max}
]

### 座標意義

* x 軸代表隨機變數 (X) 的可能取值。
* y 軸在手繪期間代表非負的相對權重。
* 正規化完成後，y 軸代表實際機率密度 (f_X(x))，單位為每一單位 x 的機率密度。
* 曲線與 x 軸之間的面積經正規化後必須等於 1。

### 筆畫驗證

* 使用 Pointer Events 統一支援滑鼠、觸控與觸控筆。
* 一次繪製由 `pointerdown` 開始，至 `pointerup` 或 `pointercancel` 結束。
* 筆畫必須大致由左向右。
* 可容許最多約 3 個 CSS 像素的反向水平抖動；超出此容許值即視為明顯回頭。
* 筆畫不得完全位於 x 軸上。
* 高於繪圖區上界的座標限制在繪圖區上界。
* 低於 x 軸的座標限制為零，不建立負密度。
* 若筆畫無效，不鎖定手繪框，並允許使用者重新畫一筆。

### 筆畫轉換

1. 將筆畫點轉換成相對座標：

   * 水平位置保存為 (u\in[0,1])。
   * 垂直位置保存為從 x 軸向上的相對高度。

2. 以固定均勻網格取樣筆畫，建議使用 1024 個原始計算點。

3. 相鄰筆畫點之間使用線性插值。

4. 筆畫未涵蓋的左右區間，其密度設為 0。

5. 將相對水平位置映射成：

[
x=x_{\min}+u(x_{\max}-x_{\min})
]

6. 將插值後的非負高度視為未正規化權重 (g(x))。

7. 使用梯形法或等價的均勻網格數值積分計算面積：

[
A=\int_{x_{\min}}^{x_{\max}}g(x),dx
]

8. 若 (A) 為有限正數，建立：

[
f_X(x)=\frac{g(x)}{A}
]

9. 對正規化後的 PDF 再做一次數值面積檢查；必要時使用離散總和作最後微量修正，確保數值面積為 1。

### x 軸範圍修改

筆畫應以相對水平座標保存，而非只保存實際 x 值。修改 (x_{\min}) 或 (x_{\max}) 後，使用相同的 (u) 對筆畫重新映射。

因此：

* 曲線在圖框中的水平相對位置不變。
* 實際 x 值改變。
* PDF 必須依新的區間寬度重新正規化。
* 期望值、標準差及卷積結果全部重新計算。

### 原始統計值

使用完整計算網格計算：

[
\mu=E[X]=\int x f_X(x),dx
]

[
\sigma=\sqrt{\int (x-\mu)^2f_X(x),dx}
]

為降低浮點誤差，可先計算二階中心矩，並將極小的負誤差截為 0，再開平方。

## CLT 展示方式

### 控制變數

主要控制變數為相加次數 (n)：

* 型態：整數。
* 預設值：2。
* 最小值：2。
* 最大值：目前的 (n_{\max})。
* (n_{\max}) 預設為 30，允許範圍為 2 至 100。

### 展示的隨機變數

顯示的是 n 個相互獨立、服從相同手繪分布的隨機變數之和：

[
S_n=X_1+\cdots+X_n
]

不除以 (n)，不轉換成樣本平均，也不進行標準化。

### 相加分布計算

* 將原始 PDF 的均勻網格轉換成離散機率質量：

[
p_i=f_X(x_i)\Delta x
]

* 對 (p_i) 進行 n 重線性卷積。
* 建議使用 FFT 實作 n 重卷積，以避免逐次直接卷積造成大量運算。
* FFT 長度至少應涵蓋：

[
n_{\max}(M-1)+1
]

其中 (M) 是原始計算網格點數；FFT 陣列長度取不小於此值的下一個 2 的次方，以避免循環卷積污染結果。

* 對原始質量陣列做一次 FFT 後，將各頻率值取 n 次方，再做反向 FFT。
* 將浮點誤差造成的極小負值截為 0。
* 對卷積後的離散質量重新正規化。
* 除以 (\Delta x)，轉回相加分布的密度值。

### n 改變時的更新

每次 (n) 改變時更新：

* 相加分布曲線。
* 相加分布圖標題。
* x 軸支撐範圍。
* y 軸自動範圍。
* 數值卷積結果的期望值與標準差。
* 理論期望值 (n\mu)。
* 理論標準差 (\sqrt{n}\sigma)。

原始 PDF、原始統計值及其圖表不需重新建立。

## 圖表與統計

### 圖一：原始分布

**標題：**「原始分布 (X)」

* x 軸：(X) 的取值，範圍為 (x_{\min}) 至 (x_{\max})。
* y 軸：機率密度 (f_X(x))。
* 視覺形式：連續實線曲線，可搭配低透明度的曲線下方面積填色。
* 圖例：「正規化 PDF (f_X(x))」。
* 重繪期間可另外顯示淡色舊曲線，圖例標示為「目前分布」；新筆畫標示為「新筆畫」。
* 完成正規化後，y 軸根據密度最大值自動縮放，並保留少量上方留白。

圖下顯示：

* 期望值：(E[X])。
* 標準差：(\operatorname{SD}(X))。
* 數值面積：(\int f_X(x),dx)，用於確認正規化結果。

### 圖二：n 個變數相加後的分布

**標題：**「相加分布 (S_n=X_1+\cdots+X_n)，n = 目前值」

* x 軸：總和 (S_n) 的取值。
* 理論支撐範圍：

[
[nx_{\min},nx_{\max}]
]

* y 軸：相加分布的機率密度 (f_{S_n}(s))。
* 視覺形式：連續實線曲線，可搭配低透明度面積填色。
* 圖例：「(S_n) 的 n 重卷積 PDF」。
* 不加入常態分布參考線。

圖下顯示：

* 卷積結果期望值：(E[S_n])。
* 理論期望值：(nE[X])。
* 卷積結果標準差：(\operatorname{SD}(S_n))。
* 理論標準差：(\sqrt{n}\operatorname{SD}(X))。

### 數值格式

* 所有主要統計值顯示至小數點後 3 位。
* 座標軸刻度可根據量級選擇一般小數或科學記號，避免標籤重疊。
* 非常接近零且只是浮點誤差的數值顯示為 `0.000`。
* 計算期間不顯示過期結果冒充新結果；保留舊圖時需加上「計算中」狀態。

### 同步規則

* (n) 改變：只更新圖二及圖二統計區。
* (n_{\max}) 改變且未影響目前 (n)：圖形可保持不變，但必須更新計算配置。
* (n_{\max}) 降至目前 (n) 以下：調整 (n) 後更新圖二及統計區。
* 原始筆畫改變：更新兩張圖及全部統計值。
* x 軸範圍改變：重新映射、正規化並更新兩張圖及全部統計值。
* 無有效 PDF 時：清除或停用結果圖，不顯示先前分布的統計值。

## Error Handling

### 無效數字輸入

處理下列情況：

* 空白。
* `NaN`。
* 正負無限大。
* 非數字字串。
* (n_{\max}) 含小數。
* 數字大到使座標、積分或 FFT 計算溢位。

提示應顯示在對應輸入框附近，並保留上一個有效值與結果。

### 不合理的參數範圍

* 若 (x_{\min}\ge x_{\max})，顯示「x 軸最小值必須小於最大值」。
* 若 (n_{\max}<2)，顯示「n_max 不得小於 2」。
* 若 (n_{\max}>100)，顯示「為避免計算時間過長，n_max 上限為 100」。
* 若 (n_{\max}) 不是整數，拒絕套用並要求輸入整數。

### 無法形成有效 PDF

處理：

* 沒有筆畫。
* 筆畫只有單一點或水平長度太短，無法插值。
* 筆畫明顯向左回頭。
* 筆畫完全位於 x 軸上。
* 筆畫正規化前的總面積為 0。
* 筆畫資料含非有限座標。
* 正規化後仍無法得到有限密度。

提示需說明具體原因，並保持手繪框可用，讓使用者直接重新畫一筆。

### 正規化錯誤

* 若數值面積小於安全容差或不是有限正數，不執行除法。
* 正規化後再次檢查離散總機率。
* 若偏差僅為浮點誤差，重新正規化。
* 若偏差過大或結果包含非有限值，停止更新圖二並提示重新繪製。

### 卷積錯誤

處理：

* FFT 結果包含 `NaN` 或無限大。
* 卷積後總質量為 0。
* 顯著負機率值，而非可忽略的浮點誤差。
* 計算工作被新的 (n) 或分布更新取代。
* 計算時間超出合理等待時間。

發生錯誤時：

* 不呈現錯誤結果。
* 保留有效的原始 PDF。
* 圖二顯示「無法計算此相加分布」及原因。
* 使用者仍可降低 (n_{\max})、調整 (n) 或重新繪圖。

### 無資料狀態

* 初始載入時，圖二顯示「請先畫出有效的原始分布」。
* 重繪期間保留舊結果，但清楚標示仍在使用目前已接受的分布。
* 若新筆畫無效，舊結果不得被無效資料覆蓋。
* 取消重繪後恢復正常狀態標示。

## Performance

### 可能的效能瓶頸

* 將高頻率 Pointer Events 直接全部保存與重繪。
* (n_{\max}=100) 時的大型 FFT。
* 快速拖曳 (n) 滑桿造成多個重複計算。
* 將十萬個以上的卷積點全部交給圖表渲染。
* 修改 x 軸範圍後，同時觸發正規化、統計及卷積。

### 筆畫處理

* 即時繪圖可依動畫幀更新，不必對每個 Pointer Event 立即重畫。
* 原始事件點可先保存，完成後再重採樣為固定的 1024 點計算網格。
* 不以畫布像素數直接決定統計計算精度，避免不同螢幕得到不同結果。

### 背景計算

* 將 FFT 與反向 FFT 放入 Web Worker。
* Worker 程式碼直接內嵌於單一 HTML，透過 Blob 建立，不使用外部檔案或 CDN。
* 主執行緒負責控制項、狀態與繪圖，避免大型卷積使介面停止回應。
* 每個計算工作帶有版本編號；較舊工作的結果回傳時，如果輸入版本已改變，直接丟棄。

### 滑桿更新節流

* 滑桿數字應立即更新。
* 卷積計算以 `requestAnimationFrame` 或短時間 debounce 合併快速輸入。
* 使用者持續拖曳時，只保留最新要求的 (n)。

### 快取

可快取：

* 正規化後的原始 PDF 網格。
* 原始 PDF 的統計值。
* 對應目前原始分布與 FFT 長度的頻域結果。
* 已完成的特定 (n) 卷積結果。
* 已降採樣的繪圖資料。

快取失效規則：

| 變更            | 失效內容                           |
| ------------- | ------------------------------ |
| (n) 改變        | 不使原始 PDF 快取失效；讀取或建立該 (n) 的卷積結果 |
| (n_{\max}) 改變 | FFT 長度、頻域資料及卷積結果快取失效           |
| x 軸範圍改變       | 原始 PDF、統計、FFT 與所有卷積快取失效        |
| 新筆畫被接受        | 所有原始統計、FFT 與卷積快取失效             |
| 取消重繪          | 若已接受資料未變，不使快取失效                |

### 計算與顯示點數

* 統計及卷積使用完整計算網格。
* 圖表繪製可將結果降採樣至最多約 1500 至 2000 個可視點。
* 降採樣只影響畫面，不得用降採樣資料計算期望值、標準差或正規化。
* 降採樣需保留局部極值，避免尖峰被平均掉。

### 計算狀態

計算超過一個動畫幀時，顯示：

* 「計算中」狀態。
* 非阻塞式進度指示。
* 已顯示的舊結果需降低透明度或標示為舊結果，直到新結果完成。

## 介面與版面

### 主要區塊

1. **頁首**

   * Demo 標題。
   * 一段簡短操作說明。
   * 不加入行銷文案、功能推銷或與教學無關的裝飾。

2. **原始分布區**

   * (x_{\min})、(x_{\max}) 控制列。
   * 原始分布手繪圖。
   * 「重繪／取消重繪」按鈕。
   * 當前狀態提示。
   * 原始分布統計值。

3. **相加控制區**

   * (n) 滑桿。
   * 目前 (n) 數字。
   * (n_{\max}) 輸入框。
   * 計算狀態。

4. **相加分布區**

   * 相加分布圖。
   * 數值卷積與理論統計值。

### 桌面版排列

* 使用垂直教學流程排列：原始分布在上，相加控制與相加分布在下。
* 兩張圖保持足夠寬度，避免座標刻度與曲線被壓縮。
* 統計值可使用緊湊的兩欄或四格排列。
* 控制項放在其所影響的圖表附近。

### 手機版排列

* 所有主要區塊改為單欄。
* 輸入框與按鈕需有足夠觸控尺寸。
* 手繪框寬度隨容器縮放，並保留合理高度。
* 繪圖期間停用頁面在手繪框內的捲動與縮放手勢，離開手繪框後恢復正常。
* 統計值改為單欄或兩欄，避免文字截斷。

### 狀態識別

手繪區至少應有以下明確狀態：

* 「等待繪製」。
* 「正在繪製」。
* 「分布已鎖定」。
* 「重繪模式」。
* 「輸入無效，請重新繪製」。
* 「正在計算」。
* 「結果已更新」。

不可只用顏色區分狀態；需同時提供文字、線型或圖示差異。

### 視覺原則

* 整體應像資料分析或教學工具。
* 使用清楚的座標軸、網格線、圖例與狀態提示。
* 已接受 PDF、新筆畫及錯誤狀態使用可辨識的不同線型或透明度。
* 保持兩張圖的線條與統計區視覺一致。
* 鍵盤焦點狀態必須清晰。
* 表單錯誤訊息應靠近對應控制項。
