Central Limit Theorem Proof

A standalone proof page following the characteristic-function derivation in outline/CLT_demo.ipynb.

Core idea: define the normalized total fluctuation, multiply characteristic functions for independent variables, and take the limit n → ∞.
Theorem Characteristic function Standardize Limit Remainder terms

Theorem Statement

Let X1, X2, ..., Xn be independent and identically distributed random variables with finite mean and variance:

E[X]=μ , E[ (X-μ)2 ]=σ2<∞

The object we care about is the sum

Y= ∑i=1n Xi

The Central Limit Theorem says that, when n is large, this sum becomes approximately normal:

Y∼ N (nμ,nσ2)

To prove that statement, define the normalized fluctuation

Z= Y-nμ σn

Showing that Z converges to the standard normal is equivalent to the statement about Y above:

Z →d N(0,1)
i.i.d. variables finite variance normalized Σ normal limit

Proof Map

define φX(t) use independence standardize each X expand φW(u) take n → ∞

1. Characteristic Function

For any random variable X, its characteristic function is

φX(t) = E[ eitX ]

Property for independent variables:

E[AB]=∫-∞∞∫-∞∞A(y1)B(y2)f(y1,y2)dy1dy2 Y1⊥Y2⇒f(y1,y2)=f1(y1)f2(y2) =(∫-∞∞A(y1)f1(y1)dy1)(∫-∞∞B(y2)f2(y2)dy2) =E[A]E[B]

If X = Y1 + Y2 and Y1, Y2 are independent, then

φX(t) =E[eit(Y1+Y2)] =E[eitY1eitY2] =E[eitY1]E[eitY2] =φY1(t)φY2(t)

This is the key multiplication rule used for the sum of many independent variables.

2. Standardize the Variables

Start with the sum

The sum is

Y= ∑i=1n Xi

Center and scale

Define the standardized single-variable fluctuation

W=X-μσ

so 𝔼[W] = 0 and 𝔼[W²] = 1.

Then the original sum and the normalized fluctuation are

Y=nμ+σ ∑i=1n Wi , Z= 1n ∑i=1n Wi

3. Characteristic-Function Limit

First write the small-argument expansion of the single-variable characteristic function in a general variable u:

φW(u) =E[eiuW] =E[1+iuW-u22W2+O(u3)] =1+iuE[W]-u22E[W2]+O(u3) =1-u22+O(u3)

For the normalized sum Z = n-1/2ΣWi, independence gives

φZ(t) =[φW(tn)]n =[1-t22n+O(n-3/2)]n

Why t / √n appears

eitZ=eit1n∑i=1nWi =∏i=1nei(t/n)Wi ⇒u=tn

Why the higher-order terms disappear

For φZ(t), the high-order part has the following scale:

O(u3) = O((t/n)3) = O(n-3/2)

Compare the two possible product scales:

(1+1n)n →e
(1+n-3/2)n →1

Taking the limit,

[1-t22n+O(n-3/2)] n → e-t2/2

To identify the limit, compute the characteristic function of a standard normal random variable G ∼ N(0,1):

φG(t)=12π∫-∞∞eitxe-x2/2dx =12π∫-∞∞e-12(x-it)2dxe-t2/2 =e-t2/2

The limiting characteristic function is therefore the one for N(0,1), so

Z →d N(0,1)

Returning to the original sum, for large n this means

Y∼ N (nμ,nσ2)
