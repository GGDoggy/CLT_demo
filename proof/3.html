Characteristic-function proof

Central Limit Theorem

When many independent variables with the same distribution are added together, their sum approaches a normal distribution.

Z= Y-nμ σn →d N(0,1)
01

The target

Start with i.i.d. variables

Let X1, ..., Xn be independent and identically distributed with finite mean and variance.

i.i.d. means independent and identically distributed: each variable follows the same distribution, and knowing one does not determine another.

i.i.d. finite variance sum Y
Y∼ N (nμ,nσ2)
Z= Y-nμ σn
Z→d N(0,1)
02

Equivalent claim

Prove the normalized version

Once Z converges to standard normal, the original sum has mean nμ and variance nσ².

Z= Y-nμ σn
Z→d N(0,1)
Y∼ N (nμ,nσ2)
03

04

Tool

Characteristic function

For any random variable X, its characteristic function is an expectation of a complex exponential.

φX(t) = E[ eitX ]

The limit theorem will be proved by showing that φZ(t) converges to the characteristic function of N(0,1).

05

Independence

The multiplication rule

If two random variables are independent, expectations of products factor into products of expectations.

E[AB]=∫-∞∞∫-∞∞A(y1)B(y2)f(y1,y2)dy1dy2 Y1⊥Y2⇒f(y1,y2)=f1(y1)f2(y2) =E[A]E[B]
06

Sums

A sum turns into a product

For X = Y1 + Y2, the exponential separates; independence then factors the expectation.

φX(t)=E[eit(Y1+Y2)] =E[eitY1eitY2] =φY1(t)φY2(t)

Repeated n times, this is the engine of the proof.

07

Standardize

Center and scale each variable

E[W]=0,E[W2]=1
W=X-μσ
Y=nμ+σ ∑i=1n Wi
Z= 1n ∑i=1n Wi
08

Expansion

Read the small-argument behavior

W is the standardized version of X. Taylor expansion plus E[W] = 0 and E[W²] = 1 leaves the quadratic term.

φW(u)=E[eiuW] =E[1+iuW-u22W2+O(u3)] =1-u22+O(u3)

Identification

That limit is the standard normal

The standard normal characteristic function is exactly e-t²/2, so the convergence of characteristic functions identifies the distributional limit.
